# Audit UI/UX và design system của sales-crm

Ngày khảo sát: 2026-10-12 (Asia/Saigon). Nguồn duy nhất là tree/blob/commit và mã nguồn GitHub của repository; không chạy mã nguồn, script hay dependency của repository nguồn.

## Provenance và kết luận

main hiện trỏ tới commit [2bb85561794d21d2af67aa7c366f40ec1ef961ee](https://github.com/kargulstudio/sales-crm/commit/2bb85561794d21d2af67aa7c366f40ec1ef961ee), commit "Add MIT License and update package.json with new project name and license". Mọi liên kết code trong báo cáo đều ghim SHA này.

Giá trị thật của nguồn nằm ở một bộ UI CRM compact: dark token system, sidebar có thể resize, header/tab rõ thứ bậc, table nhiều cột có selection, filter desktop/mobile, command palette, sheet xem nhanh và form dialog có nhóm field. Bộ primitive dựa trên Radix, Tailwind và CVA tạo được semantics/focus cơ bản.

Nguồn vẫn là frontend prototype. data/companies.ts chứa 18 record và owner cố định; stores/companies-store.ts dùng Zustand memory; lib/companies.ts suy ra health/activity từ vài số demo; TableFooter hiển thị các mục calculation nhưng không tính; tab Deals/Forecast và nhiều số đếm sidebar không có route/hành vi tương ứng. Vì vậy Fourty chỉ nên học cách trình bày và tổ chức interaction, giữ nguyên Postgres/Drizzle, RLS/RBAC, field permissions, audit và API của mình. Không sao chép record, logo, avatar, font hoặc asset media.

## Audit design system

### Token màu, type, spacing, radius và shadow

- Palette là dark-first: background #161616, card #1b1d20, popover #161616, foreground #f9fbff, muted #2a2a2a, border #232323, input/line mạnh #393939, ring #676767; semantic primary tím #4124fb, success xanh, warning vàng, danger đỏ, status teal. Sidebar có token riêng dù gần nền chung. Nguồn: [globals.css#L82-L123](https://github.com/kargulstudio/sales-crm/blob/2bb85561794d21d2af67aa7c366f40ec1ef961ee/app/globals.css#L82-L123).
- Tag palette có 10 tone, mỗi tone tách background/border/text, giúp badge giữ tương phản trong dark mode thay vì dùng màu text đơn lẻ. Nguồn: [globals.css#L125-L154](https://github.com/kargulstudio/sales-crm/blob/2bb85561794d21d2af67aa7c366f40ec1ef961ee/app/globals.css#L125-L154), mapping domain tại [data/companies.ts#L17-L41](https://github.com/kargulstudio/sales-crm/blob/2bb85561794d21d2af67aa7c366f40ec1ef961ee/data/companies.ts#L17-L41).
- Typography chỉ vài nấc có chủ đích: Geist, h1–h3 16px, h4–h6 14px, body 14px/1.15, caption/eyebrow 12px; eyebrow uppercase 1px tracking. Nguồn: [app/layout.tsx#L1-L18](https://github.com/kargulstudio/sales-crm/blob/2bb85561794d21d2af67aa7c366f40ec1ef961ee/app/layout.tsx#L1-L18), [globals.css#L191-L244](https://github.com/kargulstudio/sales-crm/blob/2bb85561794d21d2af67aa7c366f40ec1ef961ee/app/globals.css#L191-L244).
- Radius có base 0.5rem, sau đó sm = base - 4px, md = base - 2px, lg = base, xl = base + 4px. Component vẫn dùng các giá trị cụ thể như rounded-lg, rounded-xl, rounded-full; vocabulary có nhưng chưa phải mọi shadow/radius đều token hóa. Nguồn: [globals.css#L48-L57](https://github.com/kargulstudio/sales-crm/blob/2bb85561794d21d2af67aa7c366f40ec1ef961ee/app/globals.css#L48-L57), [globals.css#L82-L85](https://github.com/kargulstudio/sales-crm/blob/2bb85561794d21d2af67aa7c366f40ec1ef961ee/app/globals.css#L82-L85).
- Spacing thiên về nhịp 4/8: sidebar section p-3, header px-4 py-[14px], table head 38px, cell 42px, sheet header 56px, footer 62px, detail section p-5, dialog header px-6 py-5. Đây là mật độ phù hợp CRM quét nhanh. Bằng chứng: [sidebar-section.tsx#L16-L23](https://github.com/kargulstudio/sales-crm/blob/2bb85561794d21d2af67aa7c366f40ec1ef961ee/components/_common/sidebar/sidebar-section.tsx#L16-L23), [table.tsx#L35-L55](https://github.com/kargulstudio/sales-crm/blob/2bb85561794d21d2af67aa7c366f40ec1ef961ee/components/_ui/table.tsx#L35-L55), [sheet.tsx#L68-L91](https://github.com/kargulstudio/sales-crm/blob/2bb85561794d21d2af67aa7c366f40ec1ef961ee/components/_ui/sheet.tsx#L68-L91).
- Shadow overlay là 0 16px 40px rgba(0,0,0,.5) + 1px outline; button/card dùng nhiều inset highlight. Cách này tạo separation trong dark surface, nhưng shadow còn hardcoded rải rác ở button/card/avatar. Nguồn: [globals.css#L60-L79](https://github.com/kargulstudio/sales-crm/blob/2bb85561794d21d2af67aa7c366f40ec1ef961ee/app/globals.css#L60-L79), [button.tsx#L6-L22](https://github.com/kargulstudio/sales-crm/blob/2bb85561794d21d2af67aa7c366f40ec1ef961ee/components/_ui/button.tsx#L6-L22).

### Responsive và mobile

- Desktop sidebar từ lg; mobile header có menu button và sidebar chuyển thành left sheet.
- Desktop filter controls ẩn dưới sm; mobile dùng một bottom sheet max-height 85dvh, ScrollArea, footer cố định và result count.
